# 本地审核接口适配说明

基线：feature/school-agent-material-review，b1f9e74。
适配在隔离副本完成，尚未写回 D:\InnoGrad。

## 修改

- 保留目标目录已有的 msvcrt Windows 锁适配，并修复另一个进程占锁时读取锁文件导致 PermissionError 的问题。使用文件大小检查初始化锁文件，避免读取被锁字节。
- 中文审核规则、Skill、模拟账号和相关测试显式使用 UTF-8。
- 启动器与 Alembic 在读取数据库配置前加载同一个 backend/.env，已有进程环境优先。
- 验证工具记录 UTF-8 日志，为测试指定独立临时目录，避免 Windows 编译缓存路径过长。
- POSIX 的 0600 权限断言仅在支持该语义的平台执行；Windows 不据此宣称 ACL 已验证。账号生成、密码有效性、数据隔离和重复导入检查继续执行。
- 同步两处旧测试数据：补足审核对象字段，演示报告不再产生真实机构异常预警。
- 新增跨进程排队互斥、超时后恢复、业务异常释放和取消释放测试。

## 应用

解压整个适配包，在 PowerShell 中运行解压目录的 Apply-Adaptation.ps1。
默认目标为 D:\InnoGrad。脚本先核对所有原文件和新文件 SHA-256，遇到并发修改即停止；应用前把原文件备份至 backend/runtime/adaptation-backups。
应用后按原启动方式重启 API 和 Worker，再在 backend 目录执行 .venv 对应 Python 的 verify_local.py。
不会自动提交或推送代码，也不会自动切换模型模式。

## 当前限制

请求在 D:\InnoGrad 执行所需检查时，自动审批服务因调用不可用模型而失败，操作未执行；属于审批基础设施故障，不是风险拒绝。没有通过其他路径绕过目标目录审批。修复审批服务后可继续应用、重启和目标环境回归。
