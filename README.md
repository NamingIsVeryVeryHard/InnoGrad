# InnoGrad

研究生全培养周期智能审核与成长管理系统。

InnoGrad 面向研究生、导师、审核专家和学院管理人员，计划依托 [Inno-Agent](https://hhyqhh.github.io/inno-agent-website/)，将培养要求、学生材料、审核意见和成长记录关联起来，支持从招生到论文审查的培养过程。

项目希望帮助学生及时了解培养进度、准备材料和规划发展，也让导师与学院能够查看审核依据、跟踪培养偏差并提供支持。

**项目状态：需求分析阶段。** 当前仓库提供需求文档、目录结构和协作模板，尚无可运行版本。下文介绍的是规划中的功能。

## 项目背景

研究生培养涉及多个阶段，每个阶段都有相应的制度、材料和评价要求。学生需要了解自己完成了什么、还缺什么，以及下一步如何准备；导师和审核人员需要核对依据、反馈问题，并持续了解后续进展。

InnoGrad 聚焦这些工作之间的信息衔接：将材料与适用规则对应，将审核意见与整改记录关联，将课程、科研和实践中的证据整理为持续更新的成长记录。项目将通过实际业务案例检验能否减少重复核对、改善材料准备与培养跟踪。

## 面向谁

| 用户 | 希望完成的工作 |
| --- | --- |
| 研究生及申请人 | 对照要求准备材料，查看培养进度、成果记录和发展建议 |
| 导师 | 了解学生进展，核实成长证据，提供指导并跟踪后续改进 |
| 审核专家 | 查看材料与制度依据，复核初审意见并记录结论 |
| 学院及研究生管理人员 | 组织节点审核、招生与评奖，监测培养进展并跟踪帮扶 |

## 主要功能规划

| 业务领域 | 计划实现的内容 |
| --- | --- |
| 培养节点审查 | 招生、年度报告、资格审查、开题、中期、预答辩和论文形式审查，配套缺项提示、整改反馈和专家复核 |
| 学业与成果画像 | 课程学分、成绩、论文、项目、专利软著、奖励、交流和实践成果，形成可核验的成果账本 |
| 能力与成长画像 | 基于可观察证据呈现科研、工程、创新、协作等能力及成长轨迹，支持查看和修正 |
| 学生成长服务 | 学期进度仪表盘、材料预审、关键节点提醒、申请条件与材料助手、个性化成长建议 |
| 学院管理 | 招生筛选与导师匹配、评奖评优、培养计划偏差监测、掉队预警与帮扶、项目人才匹配和资源配置支持 |
| 基础能力 | 文档解析、规则与评价 Skills、模型接入、学生档案、角色权限和审计 |

审核意见和成长判断应能追溯到具体规则或材料。招生、资格认定、评奖和学位相关结论由有权限的人员复核，系统保留修改与处理记录。

## 技术基础

项目计划复用 Inno-Agent 的智能体运行、工作区、Skills、文档处理和分层记忆能力，在此基础上建设培养规则、学生档案、审核流程与业务应用。

多角色协作、权限和审计需要结合培养业务另行设计，具体接入方式将在工程设计阶段确定。
