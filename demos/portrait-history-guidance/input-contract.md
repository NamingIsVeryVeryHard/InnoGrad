# 输入结构

CLI 接收必需的 `--current`，可重复的 `--history`，以及可选的 `--portrait`。报告可以是 UTF-8 纯文本、bundle JSON，或含 `bundle` 字段的请求 JSON。`.json` 文件按 JSON 读取，格式错误直接报错，不降级为空材料。

bundle 使用 `student_id`、`stage`、`period` 和 `documents[].segments[]`。文档与 bundle 的学生及期间须一致；当前与历史中已知的学生标识必须一致。纯文本不推断身份，页码保持未知，正文登记为稳定段落。调用方负责明确配对及授权。已有 portrait 2.0 只提供上下文，不重新评分；学生、任务及已声明的文档版本须与当前报告匹配。

程序先按原文句界建立引用单元，以约 600 个字符为目标合并相邻句子；长句完整保留，不截断内容。每个单元保存材料、文档、页段、原文版本及 `start_char`、`end_char`。偏移使用 JavaScript UTF-16 字符串索引，区间左闭右开，可直接在原页段定位。只裁去单元边缘空白，正文不改写。

本轮向模型显示 C1、C2 等短编号；`source_id` 另行保存材料、文档、页段及原文 SHA-256，结合偏移区分同一页的不同引文。C 编号只在本次任务中有效，不作为跨版本档案 ID。模型只选择已有编号；来源表、引文原句和显示去重均由程序生成，同一来源可被多条结论复用。

此入口不读取数据库或确认业务权限；明确禁止访问、撤销、被替代或存在争议的来源会被拒绝。材料未提供可靠事件日期时，输出的 `scope.chronology` 固定为 `unknown`，历史关联只描述相关内容。

输出结构见 [输出契约](output-contract.md)，调用与复验命令见 [Demo 接入说明](README.md#研究指导-skill-的原生运行)。
