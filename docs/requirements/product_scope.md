# 产品范围

本清单定义 InnoGrad 的功能范围与业务边界，供需求讨论、任务拆分和验收使用。条目编号用于关联需求、实现任务和验收用例。

当前处于需求分析阶段，所有条目均为计划实现内容。

核心功能按培养节点智能审核、智能审核中心、学生全周期档案和成长画像组织，通过学生端和管理端使用。

系统同时建设两端。管理端是重点，详细设计规则、审核、复核、归档和培养管理；学生端保留简洁的本人材料、整改、进度、提醒与反馈入口。两端共用业务记录，具体功能编号和入口见[功能树](feature_tree.md)。

## 培养节点智能审核

| 编号 | 节点 | 覆盖内容 |
| --- | --- | --- |
| AUD-01 | 招生审核 | 资格条件、材料完整性、方向与潜力的辅助审查 |
| AUD-02 | 年度报告 | 课程学分、科研进展、交流与实践记录 |
| AUD-03 | 资格审查 | 必修环节、学术能力相关证据及资格结论的人工复核 |
| AUD-04 | 开题审查 | 选题价值、方向契合与方案可行性的辅助审查 |
| AUD-05 | 中期审查 | 里程碑达成、阶段成果、偏差与风险 |
| AUD-06 | 预答辩 | 论文完成度、主要贡献与遗留问题 |
| AUD-07 | 论文形式审查 | 格式与引用、材料清单、规范完整性 |

每个节点均应支持要求清单、缺项提示、初审意见、整改反馈与过程留痕，并提供材料完整性检查、条件符合度判断、风险提示、修改建议和专家复核入口。

不同节点共用可追溯的处理流程，采用各自适用的制度与评价依据。选题价值、创新潜力等专业判断需要专家复核，不能仅按材料字段自动作出结论。

## 智能审核中心

| 编号 | 能力 | 覆盖内容 |
| --- | --- | --- |
| REV-01 | 审核任务管理 | 统一关联培养节点、适用规则、提交材料和处理状态 |
| REV-02 | 规则与证据查看 | 将 AI 初审意见、缺项及待复核问题定位到规则版本、材料版本和引用位置 |
| REV-03 | 复核与整改闭环 | 支持专家复核、退回整改、再次核验和结果确认，保留人工修正、理由与处理记录 |

审核中心提供各节点共用的处理流程，节点条目定义具体审查内容。正式结论由有权限的人员复核确认后归档。

## 学生全周期档案

| 编号 | 能力 | 覆盖内容 |
| --- | --- | --- |
| ARC-01 | 培养记录汇集 | 关联学生信息、培养计划、课程学分、科研与实践成果及各培养节点记录 |
| ARC-02 | 材料与审核归档 | 保存材料版本、正式审核结论、复核意见和整改过程，关联适用规则版本与处理记录 |

档案保存事实与正式业务记录，为成长画像、学生端和管理端提供依据。身份、数据权限与操作审计由 BASE-05 定义。

## 成长画像

| 编号 | 领域 | 覆盖内容 | 计划输出 |
| --- | --- | --- | --- |
| PRO-01 | 纸面实力 | 课程学分与成绩，论文、项目、专利软著，奖励、交流和实践落地 | 可核验的成果账本及学业、科研和综合表现记录 |
| PRO-02 | 隐性素养 | 问题发现、分析设计、科研创新，系统实现与项目管理，协作学习、责任规范及执行表现 | 附观察证据的能力发展图谱 |
| PRO-03 | 成长轨迹 | 阶段达成、能力结构与变化、成长速度、方向匹配及风险趋势 | 成长曲线、优势短板、培养计划偏差、奖学金或项目匹配、发展建议和预警等级 |

成果数量与能力判断需要区分。画像记录应能查看来源和观察期间，并支持教师复核、学生反馈和更新。预警等级的依据、适用范围和校准方法待后续制定。

## 管理端：智能审核与培养管理（重点）

管理端面向导师、审核与培养管理人员，统一提供智能审核与培养管理功能。智能审核工作台和培养管理驾驶舱是管理端内的两个功能模块。复核、组织管理和正式确认能力分别授予，可访问的学生范围与任务由服务端检查。审核操作通过智能审核中心完成。

### 智能审核工作台

| 编号 | 场景 | 用户可完成的工作 |
| --- | --- | --- |
| TEA-01 | 审核任务与依据查看 | 查看有权处理的任务、适用规则、学生材料和 AI 初审意见，定位证据与待复核项 |
| TEA-02 | 专家复核与整改跟踪 | 按职责复核意见、退回整改、核验补充材料并确认结果，记录修正理由 |
| TEA-03 | 培养指导与成长反馈 | 查看学生档案、培养进度与画像依据，补充或修正评价，跟踪培养偏差和帮扶情况 |

### 培养管理驾驶舱

| 编号 | 场景 | 用户可完成的工作 |
| --- | --- | --- |
| ADM-01 | 招生筛选与导师匹配 | 结合成果、方向和有依据的能力信息查看候选及匹配理由，交由相关人员复核 |
| ADM-02 | 评奖评优 | 按正式规则核验资格，形成排序依据、候选名单和待复核项 |
| ADM-03 | 培养计划偏差监测 | 识别节点延误、成果不足、方向偏离及材料缺失，查看其依据 |
| ADM-04 | 掉队预警与帮扶 | 核实需要关注的情况，支持导师协同，跟踪整改、帮扶与后续变化 |
| ADM-05 | 项目人才匹配 | 根据项目要求及学生的研究方向、成果和能力证据，辅助寻找适合人选 |
| ADM-06 | 资源配置支持 | 汇总培养进展、学生需求和匹配结果，为学院提供资源配置参考；具体资源类型与配置规则待业务确认 |

评选、匹配和预警应展示依据与待核实项，支持人工调整并记录理由。仅有模型分数不足以完成这些业务。

## 学生端：成长导航（简洁入口）

学生端将材料与整改、进度与提醒、本人档案与反馈、申请与建议整理为少量入口，复用管理端使用的材料、任务和档案记录。

| 编号 | 场景 | 用户可完成的工作 |
| --- | --- | --- |
| STU-01 | 学期进度仪表盘 | 对照培养计划查看已完成、待完成及需要核实的事项 |
| STU-02 | 提交材料智能预审 | 在正式提交前查看缺项、风险提示和修改建议，补充后再次核对 |
| STU-03 | 关键节点智能提醒 | 查看项目、奖学金、年度报告、开题等重要截止事项与提醒 |
| STU-04 | 申请条件与材料助手 | 对照申请要求查看差距，整理材料清单与准备进度 |
| STU-05 | 个性化成长建议 | 根据有依据的画像与培养目标查看阶段目标、项目及能力提升建议 |

## 平台与公共能力

| 编号 | 能力 | 覆盖内容 |
| --- | --- | --- |
| BASE-01 | 智能体平台集成 | 依托 Inno-Agent 及其 Pi SDK 基础，适配会话执行、Agent 流程编排、自检与修复能力 |
| BASE-02 | 文档与数据入口 | 接收 Word、PDF、图片及 OCR 结果，处理培养计划、报告和证明，保留来源及版本 |
| BASE-03 | 规则中心与评价 Skills | 管理培养节点、规则字段、评分量表、证据核验及结果质检，支持规则版本化与 Skill 复用 |
| BASE-04 | 模型接入 | 支持结构化审核与解释，保留模型替换能力；InnoSpark 等候选模型须经实际任务验证后选择 |
| BASE-05 | 业务档案与治理 | 管理学生主档及关联业务记录，在服务端检查身份与角色、数据权限，保留日志审计并限定智能体的数据访问范围 |
| BASE-06 | 可追溯与可扩展 | 关联规则、材料、审核、画像与人工处理记录，支持增加节点、规则或业务场景 |

平台能力与建设边界见[平台说明](../software/platform_reuse.md)。

## 集成与试点交付

| 编号 | 交付内容 | 验证关注点 |
| --- | --- | --- |
| VAL-01 | 全功能集成与看板 | 节点审核、审核中心、全周期档案、成长画像及学生端与管理端能够关联使用，角色流程与视图一致 |
| VAL-02 | 试点测试与规则校准 | 使用教师提供或复核、经授权的样本，按需要脱敏，检查规则、阈值、业务流程及可用性，记录修正前后差异 |

后续验收应逐项关联上述需求编号，记录输入、适用规则、预期结果、实际结果和缺陷。除正常流程外，还应覆盖缺材料、证据冲突、规则歧义、解析失败、人工修改及权限限制等相关情况。
