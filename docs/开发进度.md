## 重要实现范围

1. 当前单一 role 及指导关系只适用于开发样例，管理范围也借用显式关系表；正式版本必须实现角色、业务范围与审核任务分离。
2. 冻结版本在 API 中无修改入口，但尚未对数据库维护身份实现不可变权限，普通审计也需数据库账号策略保护。
3. 当前任务创建即发布，规则固定为测试版本；不能据此认定模板修订模块完成。
4. 数据库归档 Worker 只做短事务处理，没有外部模型或存储调用。不能将该可靠性直接推广到长耗时 AI 任务。
5. 当前未做生产发布、学校数据接入、真实学生材料处理和 AI 外传。
