## 验证记录

- 24 项后端集成/模块测试通过（包括原有 10 项），SQLite 临时库；它们不是设计文档 T01～T24 的全量通过声明。
- 覆盖更正多轮退回后的旧档案保留、新归档切换、管理驳回、论文更新、复核责任调整、导出撤权/到期、AI 取消与迟到、过期租约恢复、模型错误保留人工通路及包外证据拒绝。
- 新增模型协议测试使用模拟 HTTP 客户端，不向真实服务传输测试或业务内容。
- 新增迁移在已有开发数据库升级成功，模型与迁移无待生成差异；原演示账号和已有工作稿保留。
- JavaScript 语法检查通过；浏览器已实际登录 v0.2 工作台。新增更正/导出控件的完整浏览器回归仍待独立验收，API 流程已由自动测试验证。
- 测试工具仍有一条 Starlette/httpx 弃用提示，未影响当前结果。

## 范围与限制

1. 现有账号仍是单角色，管理范围借用有效关系表；多重角色、组织范围、独立审核授权与名册导入未完成。
2. 论文仍使用简化提交模型；独立成果主档、共同作者申报及查重尚未落地。
3. 任务模板仍为固定测试版本，发布修订、应交名单变更与迁移未完成。
4. 作业落库与本地轮询可运行，尚未接 Redis/Celery；AI 租约和重试只提供本轮基础能力，不宣称覆盖全平台调度验收。
5. 已支持 PDF 原生文本与 DOCX 段落提取，未实现 OCR、独立解析容器或完整真实文档评测。
6. 用户选择校内/自部署模型；当前未获得真实接口地址、协议细节和模型名，默认规则模式。模型适配器已测试，真实服务尚待配置和验证。
7. 本地备份仅针对 SQLite 开发环境，不能替代 PostgreSQL/S3 恢复演练和生产 RPO/RTO 验收。
8. 前端仍为真实接口联调工具，正式 Vue 工程和完整可访问性测试未完成。
