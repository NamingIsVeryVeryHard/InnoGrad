# 竞赛与获奖及学术交流申报

学生在 InnoGrad 中除登记论文成果与年度培养报告外，还可独立发起 **竞赛与获奖**（`kind = "competition"`）和 **学术交流**（`kind = "exchange"`）材料申报。两类材料共用不可变提交版本、教师/Agent 审核、异步归档、档案更正、导出和成长画像事实映射机制。

## 1. 竞赛与获奖（`competition`）

### 1.1 表单字段（`form`）

```json
{
  "competition_metadata_version": 1,
  "title": "全国研究生数学建模竞赛",
  "competition_name": "全国研究生数学建模竞赛",
  "organizer": "中国学位与研究生教育学会",
  "award_level": "国家级一等奖",
  "award_date": "2026-10-15",
  "team_members": [
    {"name": "张三", "order": 1},
    {"name": "李四", "order": 2}
  ],
  "my_role": "队长，负责建模与核心实验验证",
  "publicity_url": "https://example.org/awards/2026",
  "description": "补充说明（选填）"
}
```

- `competition_name`、`organizer`、`award_level`、`award_date`（`YYYY-MM-DD`）、`team_members`、`my_role` 均为必填；提交时自动同步 `title = competition_name`、写入 `team_size` 与 `is_team`（`team_size > 1`），并生成规范化 `competition_key`（64 位 SHA-256 摘要，供前端展示同学生重复申报提醒）。
- `team_members` 支持文本按行/逗号/顿号输入，或传入结构化顺序列表，服务端统一规范为从 `1` 开始连续编号的成员列表（字典项可保留可选 `is_self` 标记）。
- **证明材料要求**：支持上传证书等附件（`award_certificate` 获奖证书、`publicity_proof` 公示页面或获奖名单证明、`team_role_proof` 团队成员与本人角色证明、`other_proof` 其他证明材料）或填写完整的 `http(s)` 公示链接 `publicity_url`，**两者至少提供一项**（可同时提供）。正式提交时会写入 `proof_mode`（`certificate_and_link` / `certificate_only` / `link_only`）。仅提供外部公示链接、未上传附件时，Agent 解析限制与系统指令会明确标记为 `unable_to_determine`，在 `agent` 工作流下转交授权教师或管理教师复核确认，不会自动通过。

### 1.2 画像映射

归档后的竞赛记录会在学生成长画像中保留 `proof_mode`、`team_size` 等事实快照，并按六类材料观察方向自动关联到：
- **科研训练**（`training`）：关联 `award_level`
- **课题与贡献**（`contribution`）：关联 `my_role`

## 2. 学术交流（`exchange`）

### 2.1 表单字段（`form`）

```json
{
  "exchange_metadata_version": 1,
  "title": "中国教育技术学术年会",
  "activity_name": "中国教育技术学术年会",
  "activity_date": "2026-11-10",
  "end_date": "2026-11-12",
  "participation_mode": "talk",
  "location_or_organizer": "上海 · 华东师范大学",
  "presentation_title": "面向研究生培养过程的可追溯画像方法",
  "practice_task_description": "",
  "participation_summary": "分组口头报告并参与圆桌讨论",
  "reference_url": "https://example.org/conf/2026"
}
```

### 2.2 参与方式区分与条件必填

`participation_mode` 明确区分四类参与方式：

| 取值 | 中文含义 | 条件必填字段 | 默认附件角色 | 画像归类方向 |
| --- | --- | --- | --- | --- |
| `attend` | 参会 | 无额外条件必填 | `attendance_proof`（参会证明 / 邀请函） | 学术交流（`exchange`） |
| `talk` | 作报告 | `presentation_title`（报告题目） | `presentation_proof`（作报告证明 / 议程 / PPT） | 学术交流（`exchange`） |
| `poster` | 展示海报 | `presentation_title`（海报题目） | `poster_proof`（海报展示证明 / 海报原件） | 学术交流（`exchange`） |
| `practice_task` | 承担具体实践任务 | `practice_task_description`（承担的具体实践任务） | `practice_task_proof`（实践任务证明 / 结项或考核材料） | 实践落地（`practice`） |

- `activity_name`、`activity_date`（`YYYY-MM-DD`）、`participation_mode` 为必填；若填写 `end_date`，不能早于 `activity_date`。切换参与方式时，服务端与前端会自动清空非当前模式对应的条件字段，避免历史版本残留。
- 所有学术交流申报在正式提交时至少上传一份证明附件（支持 PDF、DOCX、JPG、PNG，单份不超过 50 MB，且附件角色需属于学术交流允许的角色集合）。
