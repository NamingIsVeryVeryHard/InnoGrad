# InnoGrad 学校风格界面改版

日期：2026-11-02。

依据用户提供的截图，并通过用户当前已登录的 Chrome 窗口只读查看华东师范大学教育教学管理平台的学业生涯页面：https://byyt.ecnu.edu.cn/home/#/academic-career 。未修改学校系统中的资料或业务记录。

## 设计调整

- 统一校红主色 `#a51f35`，采用通栏顶导航与浅灰服务菜单。
- 顶栏提供实际可用的首页、学业生涯、消息中心和培养任务入口；消息数来自当前授权数据。
- 侧栏使用彩色功能图标、红色选中态，支持桌面折叠和手机抽屉导航。
- 画像页采用书页主题横幅与贯穿页面的红色学业时间轴，分为基本信息、成长画像、培养进展、成果材料。
- 统一白色圆角卡片、虚线分隔、表格、按钮、状态标签、图表、弹窗和登录页。
- 保留 InnoGrad 与上海智能教育研究院品牌；横幅为本项目原创 SVG，不包含学校页面中的个人学籍信息。
- 现有学生与模拟数据、权限、Agent 流程、预警、跟进及归档功能不变。未把学校截图中的课程或学位状态复制为本系统数据。

## 文件

- `frontend/prototype/campus.css`：全站主题与响应式样式。
- `frontend/prototype/assets/academic-banner.svg`：原创书页横幅。
- `frontend/prototype/app.js`：顶栏与导航结构；修复搜索跳转后弹窗未关闭的问题。
- `frontend/prototype/growth-ui.js`：学业时间轴结构与图表配色。

## 验证

8 项现有前端测试通过，JavaScript 语法检查通过。浏览器巡检学生管理、培养任务、Agent 审核、论文成果、成果档案、预警、规则、日志和设置页面，无脚本错误。

验证了全局搜索、搜索结果跳转、导航折叠、手机菜单和登录页。1440px 与 390px 视口下，文档滚动宽度分别等于可用宽度 1425px 与 375px，无页面横向溢出。学校站点仅作为只读视觉参考，本次不涉及后端或数据库迁移。
