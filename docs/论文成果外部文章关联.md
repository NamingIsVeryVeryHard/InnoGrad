# 论文成果与外部文章关联

学生登记论文成果时，论文工作稿的 `form` 保存论文题名、作者顺序、本人身份、发表状态、状态日期、DOI、文章链接和本人贡献。证明附件继续使用提交版本的 `file_ids`，支持 PDF、DOCX、JPG 和 PNG。

## 新增字段

```json
{
  "paper_metadata_version": 2,
  "title": "论文题名",
  "authors": [
    {"name": "作者一", "order": 1},
    {"name": "作者二", "order": 2}
  ],
  "author_order": 2,
  "author_identity": "corresponding_author",
  "publication_status": "submitted",
  "submission_date": "2026-11-20",
  "doi": "10.1234/example",
  "article_url": "https://example.org/paper",
  "contribution": "实验与分析"
}
```

`authors` 按顺序保存作者，服务端会根据 `author_order` 写入唯一的 `is_self` 标记。`author_identity` 的取值为 `first_author`、`co_first_author`、`corresponding_author` 或 `other_author`。DOI 和文章链接至少填写一项，DOI 会去除 `doi.org` 前缀并校验格式。

正式提交时，服务端将题名、完整作者顺序、DOI 和文章链接规范化后生成 `external_article_key`，并把规范化结果写入冻结版本快照的 `external_article`。同一外部文章的重复申报可以据此识别，论文申报记录仍按提交版本独立保留。

旧版本中没有这些字段的论文仍可读取。学生通过新版表单编辑并重新提交时，需要补齐作者列表、本人顺序、本人身份以及 DOI 或文章链接。

教师 Agent 论文查询会在论文结果、学生画像和证据来源中返回这些字段，并保留对应 `/form/...` 的来源指针。
