# 研序交互原型 · 2026-11-02

本次在现有需求、试点设计与 v0.2 后端基础上，新增独立本地交互原型。没有替换或改动既有业务数据库、API 和人工审核流程。

## 启动与体验

双击 `frontend/prototype/启动原型.command`，或按 README 启动后端后访问：

http://127.0.0.1:8000/prototype/

原业务登录页增加了原型入口；原型侧栏也可进入真实业务联调台。

顶部可切换管理教师、王老师、陈老师、学生林知远。三种业务角色使用不同范围；第二位导师用于验证审核责任调整。角色切换用于演示，不是生产认证。

年度报告可引用本人已归档论文，正式提交时冻结所引用的认定版本。每次补正生成新提交版本。更正或论文更新时原有效档案持续保留，新的审核通过后切换。教师侧不展示未提交的私人草稿内容。

## 数据与实现边界

- 演示使用 8 位虚构学生，与真实后端数据隔离。
- 记录保存在当前浏览器 localStorage；附件原件保存在 IndexedDB，单份最大 10 MB。
- 浏览器刷新后数据保留，清除浏览器站点数据会清除演示记录。JSON 备份不包含附件原件，也未提供恢复导入。
- JSON 导出为实际可下载文件；导入为 UTF-8 CSV，支持引号、逗号和换行转义。
- AI 区域实现字段完整性检查，不进行 PDF/DOCX 内容解析、OCR、事实核验或模型推理。
- 八维画像展示历史量表结构与已归档来源，不虚构评分；暂无正式评分快照和跨年趋势。
- 提醒仅保存到原型提醒中心，不发邮件、短信或站外消息。
- 规则修订为原型规则说明版本，未接入后端规则执行器。
- 审核归档在原型中同步完成；真实业务仍由现有后端与 Worker 执行。
- 全周期扩展阶段、学校统一认证、生产授权、独立成果主档、真实 AI、生产存储等仍按原技术设计开发，本原型不表示生产系统全部完成。

## 验证结果

- 原型 JavaScript 语法检查通过。
- 原型逻辑测试 7 项通过：44 个页面/身份渲染组合，角色数据范围、重分配、更正草稿隔离、CSV 边界、任务进度、HTML 转义与上海日期。
- 原有后端 24 项测试通过；保留一项现有 Starlette/httpx 弃用提示。
- 浏览器实测：管理教师发布任务；导师退回 V1；学生上传合成 PDF 后提交 V2；教师确认意见并归档；申请更正、批准重开并保留 V2 有效档案。
- 已巡检全部导航页面，无浏览器 error 日志。
- 移动端 390px 视口实测，文档有效宽 375px、滚动宽 375px，无页面横向溢出；表格在自身容器横向滚动。
- 浏览器验收留下的记录标注“原型验收”，附件 `workflow-fixture.pdf` 是空白合成 PDF，仅用于测试上传链路。

执行原型测试：`node --test frontend/prototype/tests/model.test.cjs`。
