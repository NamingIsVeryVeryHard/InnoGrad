# InnoGrad 画像与预警 · 2026-11-02

参考：用户提供的语雀《界面设计》 https://www.yuque.com/lanjm/ygdlgt/ny3tuwhn54ry9wnc 。网页直连返回 401，已通过本机已登录的语雀客户端阅读原页面与界面图片。采用其中的个人概览、研究目标、材料依据、里程碑、下一步行动和教师跟进结构，延续 InnoGrad 墨绿配色。

## 已实现

- 个人画像：学生切换（按权限）、学年筛选、个人信息、目标、材料/归档统计、六类材料观察雷达及来源清单、归档月份分布、下一步行动。
- 培养范围总览：教师可查看范围内学生的材料覆盖、有效档案与待跟进数量，搜索后进入个人画像；学生仅能访问本人数据。
- 成长记录：服务器持久化研究目标、里程碑、反思、阶段反馈、材料观察；计划可调整和记录完成。学生不能创建教师反馈或教师观察。
- 证据追溯：材料观察必须引用本学生当前有效档案的原文字段，服务端校验原文引用。相同版本/字段/引用去重；更正后旧版本可追溯但不继续计入当前覆盖。
- 自动预警：年度任务逾期未交、7 天内截止未交、材料退回/重开、Agent 审核异常、研究计划逾期。根据实时业务状态计算，不把服务未配置归为学生问题。
- 预警跟进：按待跟进/优先核验/已处理/全部筛选；查看来源、记录跟进、核验后排除、标记已处理。来源条件消除后自动退出待跟进队列；已有跟进历史保留。新版本或不同截止日期产生新的预警事件。
- 数据导出：当前学生与所选周期的成长档案可导出 JSON，包含目标、反馈、证据关联、统计和当前预警。
- 响应式界面：桌面双栏卡片、手机单栏；表格在容器内滚动。

## 数据口径

六类材料观察方向与历史八维材料初评、六类隐性能力量表分开，不改名或换算。雷达刻度为来源条数，缺少关联材料不表示能力为零；未生成能力评分、学生排名或资格结论。参考图中的合成分数没有写入实际数据库。

归档趋势表示当前有效档案按真实归档月份的分布，不将材料修改次数解释为跨年成长。年度只使用任务/记录明确填写的周期；未标注学年的论文保留在“全部记录”，不自动从录用日期推断学年。

预警用于培养支持，不是“学生能力差”的标签。跟进内容向学生与授权教师开放。学生可以通过既有站内提醒反馈，自动预警处理状态由教师记录。
